TITLE:
FastSIMD 0.1.3 [ALPHA-2026-08]: Hardware Vector Acceleration Engine for Java 🚀

DESCRIPTION:
Demonstrating FastSIMD, the zero-overhead C++ native SIMD vector acceleration engine for Java. Powered by MSVC AVX2 (256-bit) and SSE4.2 CPU vector intrinsics, FastSIMD processes memory buffers at up to 9.6–28.4+ GB/sec search throughput, achieving 7.8x–10.6x speedups over standard Java loops.

TECHNICAL HIGHLIGHTS:
- AVX2 256-Bit Vector Engine: 32-byte parallel byte scanning (`_mm256_cmpeq_epi8`), vector copy, and aligned memory transformations.
- Live Multi-Chunk Stream Scanning: Real-time 64 MB off-heap memory buffer scanning with instant pattern match location.
- CPUID Hardware Feature Detection: Auto-detects AVX2 / SSE4.2 / NEON vector extensions with zero-overhead fallback paths.
- Standalone JMH Benchmark Suite: Standardized benchmark Uber-JAR executable via `run-benchmark.bat`.

RESULTS:
- AVX2 Vector Search Throughput: 9.60 GB/sec (up to 28.48 GB/sec peak)
- Hardware Speedup Factor: 7.8x – 10.6x faster than standard Java scalar loops
- GC Heap Allocation Pressure: 0 bytes memory allocated
